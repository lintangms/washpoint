4. DAFTAR ENDPOINT API & HAK AKSES
--------------------------------------------------------------------------------
Base URL: http://127.0.0.1:8000/api
Header Wajib untuk Endpoint Terproteksi:
  Accept        : application/json
  Content-Type  : application/json
  Authorization : Bearer <access_token>

A. ENDPOINT PUBLIK (Tanpa Login)
  GET    /api                                 | Publik | Cek status server & daftar endpoint
  GET    /api/public/service-types            | Publik | Katalog jenis layanan laundry aktif
  POST   /api/register                        | Publik | Registrasi akun baru (role: user/admin)
  POST   /api/login                           | Publik | Login & mendapatkan JWT Bearer Token

B. AUTENTIKASI TERPROTEKSI (Login: user & admin)
  GET    /api/me                              | user & admin | Melihat profil user yang sedang login
  POST   /api/logout                          | user & admin | Mengakhiri sesi login

C. RESOURCE UTAMA & 5 MODUL ANGGOTA (Login: Bearer Token)
  Berlaku untuk seluruh resource berikut:
  - /api/users                                (Manajemen Users)
  - /api/service-types                        (Anggota 1: Jenis Layanan Laundry)
  - /api/laundry-orders                       (Anggota 2: Pesanan Laundry)
  - /api/payments                             (Anggota 3: Pembayaran)
  - /api/pickup-schedules                     (Anggota 4: Jadwal Pickup/Delivery)
  - /api/order-status-histories               (Anggota 5: Riwayat Status Pesanan)

  Method & Hak Akses pada setiap {resource}:
  GET    /api/{resource}                      | user & admin | Read semua data (beserta relasi)
  GET    /api/{resource}/{id}                 | user & admin | Read detail data berdasarkan ID
  POST   /api/{resource}                      | user & admin | Create data baru (user_id otomatis dari token)
  PUT    /api/{resource}/{id}                 | user (Milik Sendiri / Ownership) & admin (Semua Data)
  PATCH  /api/{resource}/{id}                 | user (Milik Sendiri / Ownership) & admin (Semua Data)
  DELETE /api/{resource}/{id}                 | HANYA admin (role user ditolak 403 Forbidden)

Catatan Pengujian Nilai Tambah (Ownership):
- Login sebagai `user@washpoint.test` (ID 2), coba PATCH `/api/service-types/1` (milik user 1) -> 200 OK.
- Tetap pakai token `user@washpoint.test`, coba PATCH `/api/service-types/2` (milik user2) -> 403 Forbidden.
- Login sebagai `admin@washpoint.test`, coba PATCH dan DELETE `/api/service-types/2` -> 200 OK.
